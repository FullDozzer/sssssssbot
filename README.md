# Silxnce

Telegram-бот для связи с владельцем, когда написать напрямую нельзя (спамблок, чёрный список).
Пользователь пишет боту — сообщение приходит владельцу. Владелец отвечает реплаем — ответ уходит пользователю.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Узнай свой id (например, у [@userinfobot](https://t.me/userinfobot)).
3. Настрой окружение:
   ```sh
   cp .env.example .env   # заполни BOT_TOKEN и ADMIN_ID
   ```
4. Запусти (Python 3.10+):
   ```sh
   pip install -r requirements.txt
   python -m silxnce
   ```

Docker:
```sh
docker build -t silxnce .
docker run -d --name silxnce --restart unless-stopped --env-file .env -v silxnce-data:/data silxnce
```

## Как работает

- Любое сообщение пользователя (текст, фото, файлы, голосовые, стикеры) копируется владельцу с подписью: имя · @username · id.
- Ответ владельца — реплаем на это сообщение. Пользователь получает его как ответ на своё сообщение.
- Доставка подтверждается реакцией на сообщении.
- `/ban` и `/unban` — реплаем на сообщение или с id: `/ban 123456789`. Сообщения заблокированных игнорируются.
- Антифлуд: не более 20 сообщений в минуту от одного пользователя.

## Переменные окружения

| Переменная  | Описание                                  |
|-------------|-------------------------------------------|
| `BOT_TOKEN` | Токен бота от @BotFather                  |
| `ADMIN_ID`  | Telegram id владельца                     |
| `DB_PATH`   | Путь к SQLite-файлу (по умолчанию `silxnce.db`) |
